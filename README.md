# Red Ball brand assets

Permanent public host for Red Ball Commercial Group brand files, served at
**https://assets.redballnetwork.com**.

## The one rule

**URLs in this repository are permanent. Never move or rename a file that is already live.**

Every Red Ball email signature references these files by URL. An email sent today will still
request the same URL years from now, from whatever mail client the recipient happens to open it in.
Renaming a file does not break "the website" — it retroactively breaks the logo in every email the
business has ever sent.

To change an asset, **replace the file at the same path.** To retire one, leave it in place.

## Why this exists as its own organisation

Red Ball is built to be transferable. Anything the business depends on lives on a domain the
business owns, in an account the business owns — never a personal account and never a vendor's
domain.

- `assets.redballnetwork.com` is the asset. Hosting can change behind it forever without a single
  URL breaking.
- This repository belongs to the **Red Ball Commercial Group** organisation, not to an individual,
  so ownership can be reassigned.
- GitHub Pages is free and replaceable. If it is ever left behind, repoint DNS and nothing breaks.

## Notes

- The repository is public because GitHub Pages requires it on the free plan, and because these
  files are already public by nature — the lockup appears in every email Red Ball sends.
- **Nothing confidential belongs here.** No client material, no deal documents, no internal files.
- The eXp Commercial lockup is a compliance requirement on real estate advertising, and an email
  signature counts as advertising. If this host goes down, signatures lose their brokerage
  identification. Treat availability as a compliance matter, not a cosmetic one.
